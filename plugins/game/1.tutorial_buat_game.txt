===========================================================
    TUTORIAL PARA CREAR TU PROPIO PLUGIN DE JUEGO (REFACTORIZADO V2)
===========================================================
El sistema de juegos fue refactorizado usando la arquitectura de "Plugins Auto-registrados". Esto significa que toda la configuración del juego se hace en 1 solo archivo plugin dentro de la carpeta \`plugins/game/\`.

Esta es la guía completa, profesional y con tipado estricto para crear un juego nuevo.

-----------------------------------------------------------
1. ESTRUCTURA DE ARCHIVOS
-----------------------------------------------------------
Para crear un juego nuevo (ej: Adivina el Gato), necesitas 2 archivos:
1. Archivo de datos: \`src/data/tebakkucing.json\`
2. Archivo plugin: \`plugins/game/tebakkucing.js\`
NOTA: el nombre del archivo debe ser igual en ambos, sí o sí.

-----------------------------------------------------------
2. ARCHIVO DE DATOS (VALIDACIÓN Y FORMATO JSON)
-----------------------------------------------------------
El archivo JSON debe contener un Array de Objects. El sistema tiene fallback y campos personalizables, pero por defecto espera la siguiente estructura:

A. JUEGO DE TEXTO (Estándar)
[
  {
    "index": 0,
    "soal": "¿Cómo se llama el gato que no tiene pelo?",
    "jawaban": "Sphynx"
  },
  {
    "index": 1,
    "soal": "¿Cuál es la raza de gato más grande del mundo?",
    "jawaban": "Maine Coon"
  }
]

B. JUEGO DE IMÁGENES (Basado en imagen)
[
  {
    "index": 0,
    "img": "https://domain.com/kucing1.jpg",
    "jawaban": "Anggora",
    "deskripsi": "Proviene de Turquía" // Opcional, como pregunta/nota adicional
  }
]

**Validación y requisitos del JSON:**
- El JSON debe ser válido (no se permiten comas sobrantes al final de arrays/objetos).
- Asegúrate de que la codificación del archivo sea UTF-8 (sin BOM).
- Campos obligatorios por defecto: \`soal\` (pregunta) y \`jawaban\`. Si usas otros campos, debes configurarlos en la configuración (ver las secciones \`questionField\` y \`answerField\`).

-----------------------------------------------------------
3. ARCHIVO PLUGIN (JAVASCRIPT)
-----------------------------------------------------------
Crea el archivo \`plugins/game/tebakkucing.js\` e incluye esta plantilla de código:

\`\`\`javascript
import { games } from '../../src/lib/luffy-games.js'

// 1. REGISTRO DEL JUEGO EN EL MOTOR
games.register('tebakkucing', {
    // === METADATOS ===
    alias: ['tkucing', 'guesscat'],       // (Array) Comandos alternativos
    emoji: '🐱',                          // (String) Ícono del juego
    title: 'TEBAK KUCING',                // (String) Título en mayúsculas
    description: 'Adivina la raza de gato',// (String) Descripción para el menú
    
    // === COMPORTAMIENTO Y TIEMPOS ===
    timeout: 60000,                       // (Number) Tiempo para responder (MS). Default: 60000 (60 seg)
    cooldown: 5,                          // (Number) Pausa entre comandos (Segundos). Default: 5
    
    // === RECOMPENSAS (Premios del juego) ===
    // Opcional: si no se llena, usa recompensa aleatoria automáticamente.
    // Si se pone false (rewards: false), no hay recompensa alguna.
    rewards: {
        carne: 5,                        // También se puede usar la key 'limit'
        berry: 1000,                       // También se puede usar la key 'balance'
        exp: 2000
    },

    // === CONFIGURACIÓN DE DATOS ===
    dataFile: 'tebakkucing.json',         // (String) Nombre del JSON. Default = <nombre_juego>.json
    questionField: 'soal',                // (String) Key del JSON para la pregunta. Default = 'soal'
    answerField: 'jawaban',               // (String) Key del JSON para la respuesta. Default = 'jawaban'
    
    // === CONFIGURACIÓN DE IMAGEN (Si el juego es de imágenes) ===
    hasImage: false,                      // (Boolean) ¿Es un juego de adivinar imágenes? Default: false
    imageField: 'img',                    // (String) Key del JSON con la URL de imagen. Default = 'img'
    
    // === EXTRA ===
    hintCount: 3                          // (Number) Máximo de pistas progresivas
})

// 2. EXPORTAR LA INSTANCIA DEL HANDLER (OBLIGATORIO ESTE ESTÁNDAR)
const { config: pluginConfig, handler, answerHandler } = games.createPlugin('tebakkucing')
export { pluginConfig as config, handler, answerHandler }
\`\`\`

-----------------------------------------------------------
4. CÓMO FUNCIONA EL MOTOR (Under The Hood)
-----------------------------------------------------------
1. Al cargar: \`luffy-plugins.js\` carga \`tebakkucing.js\`.
2. Registro: La función \`games.register\` guarda los parámetros de tu config en la memoria del Registry central.
3. Hooking: \`src/handler.js\` detecta la existencia del export \`answerHandler\` e intercepta todos los mensajes de texto entrantes para validar si el usuario está en una sesión de 'tebakkucing' y respondió correctamente (usando distancia Levenshtein >= 85%).
4. Recompensa: Se otorga automáticamente mediante el cálculo aleatorio de \`getRandomReward()\` (EXP, Berry, Limit) + detector de subida de nivel.

Las tres líneas de export de abajo son cruciales, está prohibido eliminarlas:
**\`export { pluginConfig as config, handler, answerHandler }\`**

¡Listo! ¡No hace falta editar más \`luffy-games.js\` ni \`handler.js\` cada vez que agregues un juego nuevo!
